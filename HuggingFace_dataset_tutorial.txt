How to Turn a Folder of CSV Files into a Hugging Face Dataset

Prerequisites

1.  Install the required packages:

    pip install datasets huggingface_hub pandas

2.  Log in to Hugging Face:

    hf auth login

Folder Structure

Example:

my_dataset/ sample_001.csv sample_002.csv sample_003.csv

Choose a Dataset Structure

Option A (Recommended) - Each CSV file represents one sample (e.g., one
experiment, trajectory, patient). - Each row in the Hugging Face dataset
corresponds to one CSV file.

Option B - Each CSV is simply a shard of one larger table. - Concatenate
all CSVs into one DataFrame before uploading.

Option A: One CSV Per Dataset Row

from pathlib import Path import pandas as pd

folder = Path(“my_dataset”)

examples = []

for csv_file in folder.glob(“*.csv”): df = pd.read_csv(csv_file)

    examples.append({
        "id": csv_file.stem,
        "trajectory": df.to_dict("records")
    })

Convert to a Hugging Face Dataset

from datasets import Dataset

dataset = Dataset.from_list(examples)

Inspect the dataset:

print(dataset) print(dataset[0])

Upload to the Hub

dataset.push_to_hub(“your_username/my_csv_dataset”)

Load Later

from datasets import load_dataset

ds = load_dataset( “your_username/my_csv_dataset”, split=“train” )

print(ds[0])

Option B: Merge All CSV Files

from pathlib import Path import pandas as pd

dfs = []

for f in Path(“my_dataset”).glob(“*.csv”): df = pd.read_csv(f)
df[“source_file”] = f.stem dfs.append(df)

merged = pd.concat(dfs, ignore_index=True)

from datasets import Dataset

dataset = Dataset.from_pandas( merged, preserve_index=False )

dataset.push_to_hub(“your_username/my_dataset”)

Recommendation

Use Option A if each CSV represents an independent sample such as a
trajectory, experiment, or patient. Use Option B only if the CSVs are
shards of the same table.

After publishing, anyone can load the dataset using:

from datasets import load_dataset

dataset = load_dataset(“your_username/my_csv_dataset”)
